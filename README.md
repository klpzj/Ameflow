# 雨课堂自动连播（Ameflow）

<https://github.com/klpzj/Ameflow>

雨课堂新版课程页的自动连播工具。打开课程页后，工具按左侧知识点目录依次播放尚未完成的视频，一节结束后自动进入下一节，全过程无需人工干预。

安装一次，适用于同一平台下的全部课程。

## 功能

### 一、自动进入并播放

当页面停留在知识点首页、显示「去学习 / 继续学习」时，工具自动点击进入并开始播放。
若播放器未能及时就绪，将自动重试，直至正常播放。

### 二、本节结束后自动进入下一节

一节播放完毕，工具先确认该节已无后续视频，再读取左侧知识点目录，选择距离当前位置最近、且尚未完成的视频节点并跳转。
目录中的作业、测验与纯图文节点在筛选阶段即被排除，无需逐个进入等待。

### 三、同一节内的多段视频依次播完

单个知识点下挂有多段视频时，工具在一段结束后继续播放下一段，待该节全部视频结束后再切换节点。
每段结束均设有确认间隔，以等待下一段视频加载完成。

### 四、切换标签页或最小化窗口时保持播放

雨课堂默认在切换标签页或最小化窗口时暂停播放。工具让页面保持前台状态，并忽略页面自身发出的暂停请求，因此在无人值守的情况下，仍可正常使用其他窗口。
用户主动暂停时，工具以用户操作为准。

## 安装

### Edge 扩展（推荐）

1. 从 [Releases](https://github.com/klpzj/Ameflow/releases) 页面下载最新压缩包并解压；
2. 在地址栏打开 `edge://extensions`，启用左侧「开发人员模式」；
3. 点击「加载解压缩的扩展」，选择解压目录中的 `edge-ext` 文件夹；
4. 打开课程页，页面右下角出现状态条即表示已生效。

### 油猴脚本（可选）

安装 Tampermonkey 后新建脚本，将发布包中的 `Ameflow.user.js` 全文粘贴并保存，刷新课程页即可。
两种方式择一安装。

## 使用

### 日常使用

打开课程页即自动开始，从当前停留位置继续播放，无需任何设置。
更换课程、学期或班级时，直接打开对应课程页即可，配置通用。

### 状态条说明

页面右下角常驻状态条，用于显示当前执行状态：

| 显示 | 含义 |
|---|---|
| `正在播放 42%` | 正常播放中，等待本节结束 |
| 第二行 `点击这里暂停 · 还剩 7 节 · v1.0` | 目录中尚有 7 节未完成 |
| `正在跳到「研究目标与科学问题」` | 正在切换至最近的未完成视频 |
| `本节还有视频，继续播放` | 本节尚有下一段视频，继续播放 |
| `正在继续播放（42%）` | 播放曾被中断，正在恢复 |
| `视频还在加载 · 12 秒后跳过` | 视频尚未完成渲染，等待中 |
| `本节已完成，切换下一节` | 本节已播放完毕，正在切换节点 |
| `此页无需观看 · 3 秒后跳过` | 作业或图文节点，予以跳过 |
| `目录里已经没有未完成的视频了` | 全部完成，保持待命，每 10 分钟核对一次 |
| `已暂停` | 用户已手动暂停 |

状态条文字即当前所处的执行步骤；功能异常时首先查看该处提示。

### 暂停与继续

点击状态条第二行，或按 `Alt+P`；再次操作即恢复播放。

### 参数调整

默认参数适用于多数网络与设备环境，建议直接使用。
若视频加载较慢、需要延长等待时间，可在源码 `src/content.js` 顶部的配置对象中调整对应项后再构建。

## 适用环境

- 雨课堂新版课程页，路径形如 `/ai-workspace/lms-graph/{课程号}/...`
- 进度依据页面中的知识点目录与「完成度：xx%」判定；平台界面大幅调整时需同步更新脚本
- 建议同一课程仅保留一个标签页，进度以该标签页为准
- 学习进度与完成度以平台记录为准
